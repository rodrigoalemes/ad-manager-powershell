# Modelo de CSV

Exemplo **ilustrativo** do formato de entrada (dados fictícios):

```csv
Nome,Sobrenome,Login,Departamento,Tipo
Ana,Souza,ana.souza,Financeiro,Usuario
Bruno,Lima,bruno.lima,TI,Usuario
svc,backup,svc.backup,TI,Servico
```

| Coluna | Descrição |
| --- | --- |
| `Nome` / `Sobrenome` | Nome de exibição da conta |
| `Login` | Identificador da conta no domínio |
| `Departamento` | Área do colaborador |
| `Tipo` | `Usuario` ou `Servico` |

> As colunas reais usadas no ambiente corporativo podem variar; este modelo serve para ilustrar o formato.
